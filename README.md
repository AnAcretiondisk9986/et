# WMU-Exam-Schedule · 期末考试时间表

2026–2027 学年第一学期期末考试时间表，**单文件静态页面，零外部依赖**，直接双击 `index.html` 即可离线使用。

**https://blog.acretiondisk.top/WMU-Exam-Schedule/**

## 功能

- **实时倒计时**：天 / 时 / 分 / 秒逐秒跳动，附进度条与「明天 / 就在今天 / 正在进行 / 已结束」状态
- **三种视图**：按日分组时间轴、卡片网格、完整表格
- **可视化**：22 天考试日历条带（区分单场 / 一天多场）、开课学院占比、统计概览
- **检索筛选**：全字段搜索、学院筛选、按时间 / 课程 / 考场 / 学院排序
- **详情弹窗**：一键复制考试信息、导出 .ics 日历（含提前 12 小时提醒）
- **主题与适配**：深色 / 浅色切换并记忆，响应式布局，打印 / 导出 PDF 样式
- **快捷键**：`/` 搜索、`1` `2` `3` 切视图、`T` 切主题、`Esc` 关闭弹窗

## 数据

共 8 场考试、6 门课程、6 个考场，跨度 2026-12-23 → 2027-01-13（滨海校区）。

修改考试数据：编辑 `index.html` 中 `EXAMS` 数组即可，其余统计、时间轴、倒计时、日历条带会自动重算。

```js
{ year:"2026-2027", term:1, course:"系统解剖学", date:"2027-01-13",
  start:"13:30", end:"15:00", room:"6111", campus:"滨海校区",
  college:"基础医学院", dept:"解剖学" }
```

学院配色在 `COLORS` 对象中配置，新增学院会自动回退到默认主题色。
